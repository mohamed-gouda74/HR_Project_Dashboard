
# HR Dashboard – Workforce Insights

## 📌 Project Overview
This is my first Data Analytics project, built using Microsoft Excel to analyze HR data and present key workforce insights through an interactive dashboard.

The dashboard helps explore employee distribution, salary information, attendance-related metrics, and workforce trends to support better HR decision-making.

## 🎯 Project Objectives
- Analyze the company's workforce distribution.
- Monitor employee salaries and department performance.
- Track overtime and employee leave patterns.
- Explore gender distribution trends over time.
- Present key HR metrics in a clear, interactive dashboard.

## 📊 Dashboard Highlights
The dashboard includes the following KPIs and analyses:

- **Total Employees:** Overall employee headcount.
- **Monthly & Annual Salaries:** Overview of salary information.
- **Employees by Department and Country:** Workforce distribution across departments and locations.
- **Overtime Analysis:** Insights into employee overtime.
- **Sick & Unpaid Leave:** Analysis of employee leave patterns.
- **Gender Distribution Trends (2016–2020):** Workforce gender trends over time.
- **Top 5 Departments by Headcount:** Identification of departments with the highest number of employees.
